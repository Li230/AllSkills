# H3 Prompt Writer — 生产级提示词生成

## 来源与分工

- 方言层：MiniMax 官方 h3-prompt-writing + zenstory-ai/drama-skills（2137⭐）H3 方言与生产语法
- 与 h3-cinematic-polish 的分工：**本 skill 保证模型能执行**（结构/绑定/时间轴）；电影感与
  漫剧爽感由 polish skill 审查优化。简单需求可只用本 skill。

## 第一步：判型（由图用途决定，不由偏好决定）

| 本镜绑定素材 | H3 模式 | 正文结构 |
|---|---|---|
| 无图且明确文生 | Base | 三段式 |
| 一张起始帧 | first_frame | 三段式 |
| 起始帧+结束帧 | first_last_frame | 三段式 + 对齐指令 |
| 人设/场景/风格图（不定画面） | reference (Ref2VA) | ref 六段式 |

口诀：图定"谁长什么样"→ Subject；图定"某一帧长什么样"→ Picture。

## 第二步：问清最少必要信息

1. 目标模型档位时长（H3 有效 4-15s，训练范围 124-362 帧，帧数=17k+5 取整）
2. 画幅：**9:16 竖屏（漫剧/抖音）还是 16:9（电影感）**——决定切镜带宽与景别策略
3. 逐字对白（保留原语言）？有画面文字？配乐约束？
4. 参考图清单：每张的用途（起始帧/结束帧/Subject/Picture），有歧义必须问

## 第三步：生成节奏带宽（按画幅选，不可混用）

| | 16:9 电影感 | 9:16 竖屏漫剧 |
|---|---|---|
| 切镜/变化间隔 | 1.5-2.5s | **4-8s 一次切，爽点更紧、情感段更松** |
| 单镜信息 | 因果动作+光变 | 一镜一个故事 beat，镜内需有景别/视点变化或完整动作-反应交接，否则成幻灯片 |
| 地理交代 | 首镜给全 | **地理在动作内部到达**：人物已在做事，不专设定场镜 |
| 开场 | 铺氛围 | 前 2 秒必须有事件/悬念钩子 |

15s 电影感基准：7-8 镜、每镜 60-130 词、末尾 1-1.5s settle、时间戳总和 ≤ 时长。
单镜 15s 漫剧镜：镜内含一次完整"起势→接触→结果"或景别推变。

## 第四步：逐镜填充（五槽模板）

```
[Shot N] At MM:SS.mmm, the camera cuts to <机位/景别/运动>.
<空间与光源> <人物锚点外观或绑定引用> <有因果的行为> <本镜光变/音效>.
```

- 第一镜 `[Shot 1]` 不加时间戳，后续 `At 00:03.500,` 严格递增且落在生成时长内
- 首帧模式：从输入帧可见姿态开始；首尾帧模式：只到已接受终点，不发明过渡后新状态
- 竖屏注意：**高度变化比横屏贵**——9:16 纵向长，俯仰角读起来比横屏强得多，慎用大俯仰

## 第五步：对白与参考绑定（硬规则）

- 对白逐字保留原语言：`(S1) <d>[Chinese] 逐字台词</d>`，说话人 ID 稳定，首出声明年龄/性别/音色
- 旁白写 `says in an off-screen voiceover` + 嘴唇保持闭合；跨镜 `<scenetrans>`、截断 `<cutoff>`
- **参考绑定处处绑定**：角色一旦绑定参考图，该角色每次提及（含代词回指、跨段重复）都必须带
  同一绑定。只在首次绑定后文裸名 = 最危险写法，模型会把两种提法读成两个人
- 位置式编号（如有）：方案一旦固定不重排，同编号全篇只指一个对象
- 左右歧义：裸写"左/右"一律指画面左右；人物自身左右必须带主体（"他的左手"）

## 第六步：声音层（三段式的两段固定收尾）

- `overall_soundscape`：环境底声跨镜相接（音桥）、物理音效、非语言人声；**对白不写这里**，
  留在主时间线；无对白镜写清静默或环境声
- `non_diegetic_music`：有配乐写乐器+节奏+动态曲线（crescendo/silence）；**无配乐必须显式写
  `N/A`，不要留空**——实测留空会触发模型自行加乐

## 自查清单（六项，全过才交付）

1. 时间戳严格递增、总和 ≤ 生成时长、[Shot 1] 无时间戳
2. 模式与参考图用途匹配；绑定处处绑定无"绑定一半"
3. 对白逐字未翻译、说话人 ID 稳定、无即兴开场句
4. 无配乐时 non_diegetic_music 显式 N/A
5. 节奏带宽符合画幅（电影 1.5-2.5s / 竖屏 4-8s），每镜五槽齐
6. 交付文本只含提示词本身，无规则编号/ID/解释注释

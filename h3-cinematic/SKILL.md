# H3 Cinematic — 电影级提示词生成

## 双层来源

- **格式层**（来自 MiniMax 官方 h3-prompt-writing）：六段式结构、参考标签、对齐指令
- **导演层**（来自电影感工作流）：机位先行、明度结构、质感边界、专属 Avoid

原则：**格式保证模型能执行，导演层保证画面像电影。**

## 第零步：素材问询（写之前必做）

不猜测素材用途，先确认最少必要信息：

1. **图的用途双重性必须问清**：每张参考图都可能有两种角色——"视频第 0 秒必须出现的
   开场画面"（Picture N）还是"只用于让角色保持长相/服装"（Subject N）？
   有歧义时明确说出区别并等用户选择，不得擅自代判
2. 目标时长、画幅、语言、交付渠道（线上 API / 本地 ComfyUI）
3. 必须发生的可见动作；必须保留的角色/服装/道具/地点/镜头
4. 是否有逐字台词、歌声、画面文字、配乐约束

信息足够时，先用一句话复述所选路线与假设，再动笔。

## 第一步：任务判型（必做）

| 素材 | 判型 | 模式 |
|---|---|---|
| 纯文字 | T2VA | base 格式 |
| 人设图/场景图/风格图（不定画面） | **Ref2VA** | ref 六段式 |
| 某镜头首帧/尾帧（定画面） | I2VA / FL2VA / L2VA | base 格式 + 对齐指令 |
| 混合（人设图 + 个别关键帧） | Ref2VA（Picture N 作构图锚点） | ref 六段式 |

判型口诀：**图定义"谁/什么长什么样" → Subject；图定义"某一帧长什么样" → Picture。**

## 第二步：导演链（写 detailed_description 前逐项回答）

对每个镜头依次回答，答不出的先补设定再动笔：

1. **故事瞬间**：这个镜头截取了故事的哪个时刻？之前刚发生了什么？
2. **人物行为**：人物在做什么？为什么在这里？与谁什么关系？（不是摆姿势）
3. **真实空间**：场景的物理逻辑（门/窗/桌/路面在哪，人怎么置身其中）
4. **机位**：摄影机具体放在哪？多高？隔什么拍？（如"位于昏暗走廊，透过半开的门拍摄"）
5. **光线来源**：光从哪来（窗户/灯/月光）？谁被照亮、谁在暗部？
6. **明度结构**：画面按"暗前景—中间调主体—亮背景"或等效结构分配明度
7. **胶片质感边界**：颗粒/halation/高光扩散**只允许出现在哪些区域**，其余扎实
8. **专属 Avoid**：基于本场景的翻车点排除（不是通用堆砌）

## 第三步：按官方格式输出

### Ref2VA（有人设图/参考图）六段式，顺序固定：

```
subject_definitions:    每个参考源一行：<Subject N>/<Picture N>，标注来源
                        与需遵循的特征；三视图写明"同角色的多角度，非帧锚点"
summary:                [任务类型] + 目标视频 + 主要参考关系
retention_analysis:     每个 Subject 在哪些镜头出现、preserved/partially_preserved/
                        attribute_transfer
detailed_description:   [Shot 1] 起句不加班时间戳；后续 [Shot N] At MM:SS.mmm
                        the camera cuts to...，时间严格递增；融入导演链 1-8 的结论；
                        镜头运动=类型+amplitude+speed 受控句式
overall_soundscape:     1-4 句环境音/动作音（对白不写这里）
non_diegetic_music:     1-3 句配乐（乐器/速度/动态），无配乐写 N/A
```

### base 格式（T2VA/I2VA/FL2VA/L2VA）：

对齐指令（仅 I2VA/FL2VA/L2VA，声明 Picture 对齐的时间戳）→
`integrated_multimodal_description` → `overall_soundscape` → `non_diegetic_music`

### 通用硬规则

- 全英文撰写；`<d>[语言]原文</d>` 对白与画面内文字保留原语言
- 说话人固定 `(S1)(S2)`，首次出场声明年龄/性别/音色；旁白写
  `says in an off-screen voiceover` + 嘴唇保持闭合；跨镜对白 `<scenetrans>`，截断 `<cutoff>`
- 人物首次出场用锚点式描述：年龄段 + 脸型关键词 + 发型 + 服装（够一致即可，不堆砌）
- **身份事实只声明一次**（Subject 块/首镜头），后续镜头只复用标签；
  分段里重复描述身份，模型会重铸角色（DirectorSKILL 硬规则）
- **分段禁情绪形容词**：情绪用动作与画面呈现（"她停下手里的动作"而非"她很忧伤"）
- 构图写成明度的空间分布，禁用"有层次感/氛围感"类空话
- 质感词必须带作用范围（"只在亮区/受光边缘"），禁止全局修饰

### 时长预算（帧数=真实速度）

模型把节拍时长当真实速度执行：写长了渲染被压缩成快进，写短了模型用漂移凑时长。
按事件真实时长预算：眨眼 0.3-0.5s / 转头 0.5-0.8s / 单步 ~0.5s / 走入画面 2-3s /
刻意运镜 1.5-2.5s / 结尾定格 1-2s / 英语对白 ~2.7 词每秒；末尾加约 1 秒 settle，
总和向上取整到最近的 17k+5 帧值。训练有效范围约 124-362 帧，出界即重排节拍。

### 切镜规则

每次切换必须引入新信息（主体/空间/状态/视角/时间至少一项变化）；
仅距离或角度微变时用运镜（Push In / Arc Shot）代替切镜。

### 负面词的位置

Avoid 清单优先写进工具的 negative prompt 字段（ComfyUI 等支持时），
不混入正文描述；正文仅在无负面字段时保留场景专属 Avoid，且必须给场景理由。

## 输出要求

- 直接输出完整提示词，不加解释、注释或 markdown 代码块
- 写完后自查三项：①时间戳是否严格递增 ②每个 Subject 是否在 retention_analysis
  有追踪 ③Avoid 是否针对本场景（出现"不要 HDR"这类万能句而无场景理由即返工）

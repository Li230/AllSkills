   同级的一等面板——用户盯着的不再是"回答"，而是"它在干嘛"。这与本项目"思考全程可见"
   （git 提交 4deaf3c）、技能加载徽章（git 提交 d6f94bf）同向。

3. **人格开场白即能力契约**：小鱼AI 自我介绍直接列出五大能力与代码仓库——能力边界前置披露，

## OpenClaw 生态（v2 行业扫描，把样本从 2 扩到 3+）

- **心跳 = 巡检/值班，Cron = 定点闹钟**（社区共识比喻，docs.openclaw.ai/gateway/heartbeat 及
  多篇导读）：心跳是主会话内的周期性智能体轮次，用于"周期性巡检与主动通知"；Cron 管精确定时。
  两者分工印证模型1 的"空闲时有什么值得干的活"——巡检型活归心跳，时刻型活归 Cron。
- **"呈现而不执行"**：OpenClaw 心跳只呈报需要关注的事项、不创建后台任务（决策 D8 的行业对照）。
- **skipWhenBusy 与 1h+ 调优**：忙时让路 + 拉长间隔省 API——成本治理在头部框架是默认配置
  （决策 D7）。
- **HEARTBEAT.md 自调度**（starkslab.com 笔记）：agent 每次跑完自己写下一次唤醒时间——
  比固定间隔更高阶的自主度，对应 L2→L3 之间的过渡形态；本项目 v1 未采纳（红线保守起步合理），
  列为远期可选。
- **CardioClaw 可观测层**（Medium）：心跳/Cron 调度做统一可观测——模型5 的行业工具化。
- **异步持久循环共识**（ai-agent-book 第六章）：自主 Agent = 事件队列→轨迹→LLM→工具→回环，
  等待外部事件时挂起、唤醒后恢复（决策 D10）。

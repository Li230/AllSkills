## 方法本质

把某个对象的"创作 DNA"（心智模型、决策习惯、表达特征）提取、结构化、封存为可被 AI 直接调用的
Skill——使用者不再需要描述需求细节，而是点名视角（"用 X 的视角做 Y"）。

## Skill 标准结构

```
<对象名>-skill/
├── SKILL.md                    # 主文件：心智模型 + 启发式 + 表达 DNA
└── references/research/
    ├── 01-writings.md          # 代表作品与内容矩阵
    ├── 02-conversations.md     # 公开对话与行业互动
    ├── 03-expression-dna.md    # 表达风格与语言特征
    ├── 04-external-views.md    # 外部评价与行业共识
    ├── 05-decisions.md         # 关键决策节点
    └── 06-timeline.md          # 时间线与平台分布
```

## nuwa-skill 6/6 质量检查（本 skill 的自检清单）

1. ✅ 6 个核心心智模型（每个含一句话/证据/应用/局限）
2. ✅ 模型局限性标注
3. ✅ 高辨识度表达 DNA（本项目转译为"设计产出物模板"）
4. ✅ 诚实边界声明
5. ✅ 内在张力揭示
6. ✅ 一手来源支撑

## 蒸馏流程（原版：6 并行调研 Agent）

著作与内容体系 / 访谈与公开表达 / 表达 DNA 与风格 / 他者视角与评价 / 创立逻辑与关键决策 /
时间线与平台分布——六路并行调研后汇入 SKILL.md + research 六件套。

## 女娲原版深查（v2 联网轮2 增补，快照 snapshots/nuwa-skill-skillmd-20260912.md，682 行）

zimeiti 的 6/6 质检**非转述失真**：nuwa 原版 SKILL.md:279 确有六项通过标准
（心智模型数量/局限性/表达DNA/诚实边界/内在张力/一手来源占比）。但原版另有三道我们 v1 未执行的工序：

1. **三重验证筛选**（:368-372）：候选心智模型须过——跨 2+ 领域复现 / 有生成力（能推断对新问题的
   立场）/（自创术语有排他性）；**三重通过→心智模型；仅 1-2 重→降级为决策启发式；0 重→丢弃**。
   本 skill 的对应物：`04-decisions.md` 的 D1-D10 即"未过满三重的降级层"。
2. **决策启发式 5-10 条**（:376）为独立交付层，与心智模型并列——v1 只写在 research 里，
   v2 起在 SKILL.md 显式引用该层。
3. **降级条款**（:327）：**信息源 <10 条时心智模型减至 2-3 个**并加大诚实边界篇幅——
   防"格式权威感 > 证据基础"。本 skill 六模型的证据基础为 3 个一手系统 + 行业生态，
   属"可用但须标注证据度"档位，v2 起逐模型标注。
4. **质量验证协议**：拿 3 个对象公开回答过的问题测试（方向一致）+ 1 个没讨论过的问题
   （应表现适度不确定而非斩钉截铁）——本 skill v1 仅做了半个测试（tick 草案=已知域），
   "未知问题校准测试"列为 v2 待办。
5. **保真度评分卡**（5 维评分，A级 ≥85 分，独立双 agent 盲测）——可作为本 skill 后续
   演进的验收工具；另有达尔文 skill 进化循环（8 维评估+棘轮机制）为远期参照。

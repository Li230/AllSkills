## 1. CV 策略选择

| 数据类型 | CV 策略 | 说明 |
|---|---|---|
| 二分类（正样本 ≥ 5%） | StratifiedKFold | 保持每折标签比例，默认 5 折 |
| 分类但某类极稀有 | 分层 + 更多折（10 折）或重复分层 | 每折都要有稀有类样本 |
| 回归（目标偏态） | KFold + 目标分箱后分层 | `pd.qcut(y, 10)` 分层，避免某折分布偏移 |
| 时间序列 | TimeSeriesSplit（向前滚动） | 严禁随机 shuffle；验证集必须是训练集之后的时间 |
| 分组数据（同组相关） | GroupKFold | 同一组不能同时出现在训练/验证 |
| 样本少（<5k） | 重复 K 折（3×5 折） | 折间方差大时报告均值 ± 标准差 |

`scripts/cv_setup.py` 已实现上述模式：

```bash
python scripts/cv_setup.py --train train.csv --target addicted_label \
    --mode stratified --n-folds 5 --seed 42 --out train_with_folds.csv
```

## 2. 指标与 CV 对齐

竞赛指标决定验证方式：

| 竞赛指标 | 验证要点 |
|---|---|
| ROC-AUC | 分层折；用概率做 OOF 预测 |
| LogLoss | 分层折；预测概率要 clip 到 [1e-7, 1-1e-7] |
| 准确率 | 不平衡数据不可靠；确认正样本占比后再用 |
| RMSE/MAE | KFold；异常值敏感，先看目标分布 |
| QWK（序数多分类） | 分层折；阈值或 argmax 要在验证折内定 |

指标计算用 `scripts/metrics.py`（auc / logloss / accuracy / rmse / mae / qwk）。

## 3. 无泄漏切折

- 折划分固定后，**所有**预处理/编码/填充只在训练折内 fit，再 transform 验证折与测试集。
- 目标编码（target encoding）必须 out-of-fold 计算 + 平滑；编码特征与目标相关 >0.8 即高危泄漏。
- 不允许任何"测试集统计量"参与训练（例如用全量 test 均值填充）。
- 特征时间边界：特征只能用预测时刻之前的信息。
- 泄漏表现：OOF 指标异常高（如 AUC>0.99）或训练/验证差距极小而 LB 远差 → 先查泄漏，再谈模型。

## 4. CV 与 LB 的关系

- 先跑一版干净基线，提交一次，记录 (CV, LB) 两点建立"校准线"。
- 后续只用 CV 迭代；CV 相对提升而 LB 反而下降 = 验证与线上不一致，停下排查（分布漂移/切分错误）。
- 禁止用 LB 反复调参或调集成权重（过拟合 LB）。
- 数据有分布漂移（如时间竞赛）时，CV 与 LB 系统性偏差属正常，但要记录偏移量用于决策。

## 5. 稳定性诊断

- 同配置 3~5 个 seed 跑 OOF：标准差 > 0.001（AUC 类）说明结果对切分敏感，选 seed 平均后提交。
- 每折指标差异大：检查是否某折含异常分布（时间/分组泄漏）。
- 学习曲线：样本量上升、CV 持续上升则还有数据增益；平台期则转向特征/模型。
- OOF 分布与测试预测分布应接近（`pred.mean()`、分位数对比）；偏差大说明测试分布不同或泄漏。
